# Docker — قالب موحّد لتشغيل التطبيقات + عرض حي

الـ Repository ده فيه **تطبيق تجريبي عملي** (طلبات الدعم الفني)، و**Dockerfile موحّد** يستخدمه أي فريق كقالب، وقوالب جاهزة للغات التانية، وسكربت بيمشي على سيناريو العرض خطوة بخطوة.

> كل البيانات في التطبيق تجريبية، والتطبيق مش محتاج إنترنت ولا بيحمّل أي حاجة من برّه (لا خطوط ولا صور ولا CDN) — يعني يشتغل على شبكة مغلقة عادي.

## التطبيق: «طلبات الدعم الفني»

منظومة داخلية بسيطة لتسجيل طلبات الدعم الفني بين الإدارات (تكنولوجيا المعلومات، الشؤون الإدارية، الموارد البشرية، الحسابات).

| الإصدار | المميزات |
|---|---|
| **v1** (الشارة زرقاء) | تسجيل طلب (العنوان، الإدارة، الأولوية: عادي / عاجل) + عرض الطلبات من الأحدث للأقدم |
| **v2** (الشارة خضراء) | كل مميزات v1 + بحث + زر «تم الحل» لكل طلب + عدّادات (مفتوح / تم الحل) |

- الانتقال من v1 لـ v2 بيتم **بتغيير رقم الإصدار بس** (`APP_VERSION`) — من غير أي تعديل في الكود أثناء العرض.
- أعلى الصفحة بيظهر: رقم الإصدار، اسم الـ Container اللي ردّ، وحالة التخزين («متصل بقاعدة البيانات» أو «تخزين مؤقت»).
- **التخزين:** لو `DATABASE_URL` موجود → PostgreSQL. لو مش موجود → تخزين مؤقت في الذاكرة فيه 3 طلبات تجريبية (مناسب لـ `docker run` لوحده أو Render).

### الـ Endpoints

| Method | Path | الوصف |
|---|---|---|
| `GET` | `/` | الصفحة الرئيسية |
| `GET` | `/health` | فحص الصحة + حالة التخزين (JSON) |
| `GET` | `/api/tickets` | قائمة الطلبات (في v2 تقبل `?q=` للبحث) |
| `POST` | `/api/tickets` | طلب جديد: `{"title":"...","department":"it","priority":"urgent"}` |
| `PATCH` | `/api/tickets/:id` | تغيير الحالة `{"status":"solved"}` — **v2 بس** |
| `POST` | `/crash` | يوقّف التطبيق عمدًا لعرض الـ Self-healing — شغّال بس لو `DEMO_MODE=true` |

قيم `department`: `it` · `admin` · `hr` · `finance` — وقيم `priority`: `normal` · `urgent`.

## محتويات المجلد

```
├── Dockerfile              ← القالب الموحّد (مثال Node.js) — مشروح سطر بسطر
├── .dockerignore           ← الملفات اللي ممنوع تدخل الـ Image
├── docker-compose.yml      ← البيئة كاملة بأمر واحد: app + PostgreSQL
├── .env.example            ← الإعدادات وكلمات المرور (انسخه لـ .env)
├── src/                    ← كود التطبيق (Node.js 22 + مكتبة pg بس)
├── demo/run-demo.sh        ← سكربت العرض الحي (8 خطوات، ENTER لكل خطوة)
├── templates/              ← قوالب Python و .NET و Java والـ Frontend + القواعد العشر
├── .devcontainer/          ← تشغيل فوري على GitHub Codespaces
├── .github/workflows/      ← لينك عام مؤقت من GitHub Actions
└── render.yaml             ← نشر مجاني بلينك دائم على Render
```

## التشغيل على جهازك

محتاج Docker بس (Docker Desktop أو Docker Engine).

```bash
cp .env.example .env          # اختياري: غيّر كلمة سر قاعدة البيانات
docker compose up -d --build  # تشغيل التطبيق + قاعدة البيانات
# افتح http://localhost:8080
./demo/run-demo.sh            # أو شغّل سيناريو العرض كامل خطوة بخطوة
docker compose down -v        # إيقاف ومسح كل حاجة
```

- `AUTO=1 ./demo/run-demo.sh` بيشغّل الخطوات كلها ورا بعض من غير ما تدوس ENTER (مفيد للبروفة).
- السكربت بيبدأ دايمًا من بيئة نضيفة (بيمسح الحاويات والبيانات القديمة).
- تشغيل حاوية واحدة من غير قاعدة بيانات: `docker build -t demo-app:1.0.0 . && docker run -d -p 8080:8080 demo-app:1.0.0`

## التشغيل من غير ما تسطّب حاجة

| الطريقة | الاستخدام | ملاحظات |
|---|---|---|
| **GitHub Codespaces** (الأفضل للعرض) | العرض الحي بالأوامر | Docker جاهز، 120 ساعة مجانًا شهريًا للحسابات الشخصية |
| **GitHub Actions — Demo Link** | لينك عام مؤقت للتطبيق كامل (مع PostgreSQL) | لحد 5 ساعات لكل تشغيل |
| **Render** | لينك دائم تحطه في العرض | حاوية واحدة بتخزين مؤقت، بتنام بعد 15 دقيقة من غير زيارات |

### 1) GitHub Codespaces — للعرض الحي

1. من صفحة الـ Repository: **Code ← Codespaces ← Create codespace on main**، واستنى حوالي دقيقتين.
2. في الـ Terminal: `./demo/run-demo.sh`
3. افتح تبويب **Ports** ← المنفذ `8080` ← أيقونة الكرة الأرضية.
   لو عايز الحضور يفتحوه من أجهزتهم: كليك يمين ← **Port Visibility ← Public**.
4. بعد العرض: اعمل **Stop** للـ Codespace عشان الساعات المجانية متخلصش.

### 2) GitHub Actions — لينك عام مؤقت

1. من الـ Repository: **Actions ← Demo Link ← Run workflow**، واختار المدة بالدقائق (أقصى حاجة 300).
2. الـ Workflow بيشغّل `docker compose up`، يستنى لحد ما `/health` يرد، وبعدين يفتح Cloudflare quick tunnel.
3. اللينك بيظهر في خطوة **Open public link** وفي الـ Summary بتاع التشغيل (شكله `https://xxxx.trycloudflare.com`).
4. لإيقافه بدري: **Cancel workflow**.

### 3) Render — لينك دائم

1. ادخل render.com وسجّل بحساب GitHub.
2. **New ← Blueprint** ← اختار الـ Repository ← **Apply** (بيقرا `render.yaml` لوحده).
3. بعد ما البناء يخلص هيظهر لينك زي `https://docker-demo-xxxx.onrender.com`.
4. **افتح اللينك قبل العرض بـ 5 دقايق** عشان يصحى.

> على Render التطبيق بيشتغل حاوية واحدة بـ «تخزين مؤقت»: البيانات بترجع للـ 3 طلبات التجريبية مع كل إعادة تشغيل.

## سيناريو العرض (حوالي 10 دقايق)

| # | الخطوة | الأمر | اللي الحضور هيشوفه |
|---|---|---|---|
| 1 | القالب الموحّد | `grep -vE '^\s*(#\|$)' Dockerfile` | Dockerfile قصير وواضح |
| 2 | تشغيل البيئة كاملة | `docker compose up -d --build` | التطبيق + قاعدة البيانات شغّالين بأمر واحد |
| 3 | تسجيل 3 طلبات | `curl -X POST http://localhost:8080/api/tickets ...` | الطلبات ظاهرة في الصفحة |
| 4 | الأمان | `docker compose exec app id` | التطبيق شغّال بمستخدم عادي `node` مش root |
| 5 | الـ Self-healing | `curl -X POST http://localhost:8080/crash` | الحاوية وقعت ورجعت لوحدها، والبيانات زي ما هي |
| 6 | التحديث لـ v2 | `APP_VERSION=2.0.0 docker compose up -d --build app` | شارة خضرا + بحث + زر «تم الحل»، والطلبات موجودة |
| 7 | الرجوع لـ v1 | `APP_VERSION=1.0.0 docker compose up -d app` | رجعنا للإصدار القديم في ثواني، والبيانات سليمة |
| 8 | السجلات | `docker compose logs --tail 5 app` | سجلات JSON منظمة من مكان واحد |

## ملاحظات مهمة

- **الأسرار:** مفيش أي كلمة سر جوّه الـ Image. بيانات قاعدة البيانات بتيجي من `.env` وقت التشغيل، والملف ده مش بيترفع على Git.
- **الترخيص:** Docker Engine على Linux مجاني (Apache 2.0). أما Docker Desktop على Windows/Mac فمحتاج اشتراك مدفوع للجهات الحكومية — البدائل المجانية: Podman Desktop أو Rancher Desktop أو تشغيل العرض على Codespaces.
- **الأمان:** ممنوع رفع أي كود أو بيانات حقيقية تخص الجهة على المنصات العامة — التطبيق ده تجريبي بس.
- **قوالب .NET و Java** اتعمل لها فحص صياغة بس، وهتتجرب على أول تطبيق فعلي.
